# Contributing

## Purpose
This file defines lightweight contribution expectations for keeping the IP Alive documentation clear, ethical, and portfolio-ready.

## Project Status Note
This project is private, exploratory, and not affiliated with any named IP company. Any references to real companies should be treated only as hypothetical examples or future case-study candidates, not clients or partners.

## Contribution Guidelines
- Use professional English suitable for graduate-level product documentation.
- Label unverified concepts as assumptions or hypotheses.
- Avoid claiming partnerships, client relationships, research findings, legal conclusions, or market statistics without evidence.
- Keep early-stage files concise and easy to revise.
- Do not add application code, frameworks, package files, or dependencies unless the project scope changes.

## Review Questions
- Is the claim supported, or should it be labeled as an assumption?
- Does the language avoid implying affiliation with any named IP company?
- Does the update support HCI, UX, AI product, business, or safety exploration?

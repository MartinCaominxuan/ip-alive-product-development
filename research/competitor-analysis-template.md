# Competitor Analysis Template

## Purpose

Offer a reusable template for comparing adjacent products without asserting unverified market conclusions.

## Project Status Note

This project is private, exploratory, and not affiliated with any named IP company. Any references to real companies should be treated only as hypothetical examples or future case-study candidates, not clients or partners.

## Guiding Questions

- What category does the product occupy?
- What user need does it appear to address?
- What evidence supports each comparison?

# Privacy and Data

## Purpose

Document privacy questions for daily-life data such as calendars, reminders, nutrition logs, exercise tracking, budgeting, and memories.

## Project Status Note

This project is private, exploratory, and not affiliated with any named IP company. Any references to real companies should be treated only as hypothetical examples or future case-study candidates, not clients or partners.

## Guiding Questions

- What data is necessary for each use case?
- What data should never be collected?
- How can users access, correct, export, or delete data?

## Assumptions and Hypotheses

- Assumption: Data minimization should be a core requirement rather than a later optimization.

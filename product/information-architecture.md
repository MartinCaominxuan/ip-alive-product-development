Sketch the major information areas needed for character ownership, daily-life tools, safety controls, and enterprise management.

## Project Status Note

This project is private, exploratory, and not affiliated with any named IP company. Any references to real companies should be treated only as hypothetical examples or future case-study candidates, not clients or partners.

## Guiding Questions

- How should users move between collection, character chat, routines, and settings?
- Where should spending and privacy controls live?
- What admin structures are needed for IP owners?

# User Flows

## Purpose

List candidate user flows for future mapping and prototyping without treating them as finalized designs.

## Project Status Note

This project is private, exploratory, and not affiliated with any named IP company. Any references to real companies should be treated only as hypothetical examples or future case-study candidates, not clients or partners.

## Guiding Questions

- How does a user unlock a character from a physical collectible code?
- How does a user configure reminders, alarms, or budgeting support?
- How are consent, age, privacy, and spending controls surfaced?

## Assumptions and Hypotheses

- Assumption: The unlock flow may be central to connecting physical and digital ownership.

# Memory Model

## Purpose

Outline early questions for handling user preferences, relationship progression, and data minimization in character memory.

## Project Status Note

This project is private, exploratory, and not affiliated with any named IP company. Any references to real companies should be treated only as hypothetical examples or future case-study candidates, not clients or partners.

## Guiding Questions

- What should the character remember by default?
- What should require explicit consent?
- How can users inspect, edit, or delete memories?

## Assumptions and Hypotheses

- Assumption: Relationship progression should avoid manipulative dependency and should be transparent to users.

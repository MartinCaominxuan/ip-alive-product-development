# Character Safety Rules

## Purpose

Capture initial safety considerations for AI companions that use beloved fictional characters.

## Project Status Note

This project is private, exploratory, and not affiliated with any named IP company. Any references to real companies should be treated only as hypothetical examples or future case-study candidates, not clients or partners.

## Guiding Questions

- What topics should characters avoid or escalate?
- How should financial, health, and emotional-support boundaries be communicated?
- What safeguards are needed for minors?

## Assumptions and Hypotheses

- Assumption: Characters should not provide legal, medical, or financial conclusions as authoritative advice.
